# Separation Table 0.1.0

The first numbered release of the Separation Table: color
separations for screen printing, in the browser.

- Simulated process, spot, index, CMYK and 1 to 3 color jobs,
  with an automatic underbase and highlight white.
- Auto picks the method, the screens, the print order and the
  settings, and keeps a method you pick.
- Checks before you print, with one-tap fixes, and an
  out-of-gamut list that names the colors your inks miss.
- One ZIP per job: 1-bit TIFF films in print order, a film PDF,
  EPS, SVG for spot plates, a Multichannel Photoshop file, a
  job sheet, an ink mix sheet, a proof picture and
  `separation.json`.
- Save into a folder writes the same files into your RIP's hot
  folder (Chrome and Edge).
- Calibrate the ink model to your press from a printed chart.
- Films right reading or mirrored. Name a screen, print it
  twice (double hit), or merge it into another screen.
- Fabric, platen, film and screen sizes, with size checks.
- Undo and Redo. The last job comes back after a reload.

## Present in the code, not shown yet

Written and tested, but not on the page in this release
(`?later=1` shows them): several open jobs; Press and Stack
views; shop and press profiles, check limits, units, test
films, Report a problem; the press time estimate; the DCS 2.0
file; dot shapes other than round; re-proof of separated
films; the MCP server. The `sep` command-line tool is
experimental.

## Use it

Open
https://americandreamnetwork.us/tools/textile-services/screen-printing/separation-table
in a browser. Nothing to install. The version shows in Help,
on the job sheet and in `separation.json`.

To run it yourself: `npm run setup`, then `npm start` (README,
Run it locally).

## Checks in this release

- Every file in the job ZIP is read back by our own readers,
  and by Ghostscript, libtiff, Pillow and psd-tools where
  they are installed (`tests/outside-readers.py`).
- Status in the README is built from the test output.

## Checksums

`src/vendor.sha256` holds the SHA-256 of every library and
model the page serves, as pinned in `scripts/vendor-pins.mjs`.
Check a copy with `sha256sum -c vendor.sha256` in `src/`, or
`node scripts/notices.mjs --check`. Third-party licenses: THIRD-PARTY-NOTICES.md.

## Known limits

- The ink model is not calibrated to a press yet: every ΔE is
  a model number until a measured press run is published.
- No DCS 2.0 file on the page yet; each plate is its own EPS.
- Round dots only on the page.
